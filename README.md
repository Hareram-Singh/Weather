# Weather
**Weather App 🌦️** – A simple app using HTML, CSS &amp; JS with OpenWeather API. Get real-time weather, 24-hour &amp; 5-day forecasts. Switch between °C/°F, auto-detect location, and see dynamic backgrounds based on temperature. Fully responsive for all devices. Just enter a city name &amp; get instant weather updates! 👨‍💻 Developed by Hareram Singh.
